# ほの暮らしコンプチェッカー v0.2.6

- GitHub Pages上の `initial_item_master.csv` を起動時に毎回読み込みます。
- 取得済み/未取得とサイト内編集データは既存LocalStorageを引き継ぎます。
- 対応加工機候補、植付季節、収穫季節、使用材料、対応加工機を管理できます。

## v0.2.6
- `initial_item_master.csv` から消えていた以下の列を復元しました。
  - 取得状況
  - 使用材料
  - 対応加工機
  - 最終更新
- CSV列は既存項目を削除せず、植付季節・収穫季節を追加する構成に統一しました。
- CSVの「取得状況」が取得済の場合、ブラウザにその図鑑番号の取得状況がまだ保存されていないときだけ初期値として反映します。既存のLocalStorage側の取得状況を優先します。
- CSV書き出しでは15列すべてを保持します。
