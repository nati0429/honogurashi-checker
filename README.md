# ほの暮らしコンプチェッカー v0.2.10

- GitHub Pages上の `initial_item_master.csv` を起動時に毎回読み込みます。
- 取得済み/未取得とサイト内編集データは既存LocalStorageを引き継ぎます。
- 対応加工機候補、植付季節、収穫季節、使用材料、対応加工機を管理できます。

## 更新ルール
- 機能やデータを更新するたびにバージョン番号を上げます。
- そのバージョンの更新内容をREADMEの変更履歴に記載します。

## v0.2.10
- `initial_item_master.csv` を最新の提供データに差し替えました。
- 2,428件・15列のデータ構成を維持しています。

## v0.2.9
- カテゴリカードの初期表示を「加工品」「魚」「種・苗」「料理」の4つにしました。
- それ以外のカテゴリは初期状態では非表示とし、「表示するカテゴリを設定」から任意に表示できます。

## v0.2.8
- `initial_item_master.csv` のカテゴリ列に登録されたすべてのカテゴリについて、上部に取得状況カードを自動生成するようにしました。
- 各カードに「取得済み数 / カテゴリ総数」と取得率を表示します。
- 「表示するカテゴリを設定」から、カードをカテゴリごとに表示・非表示にできるようにしました。
- 「すべて表示」「すべて非表示」を追加し、表示設定をLocalStorageとJSONバックアップに保存するようにしました。

## v0.2.7
- 上部に「種・苗」「加工品」「料理」のカテゴリ別カードを追加しました。
- 各カテゴリについて「取得済み数 / カテゴリ総数」と取得率を表示します。
- アイテムの取得状態やカテゴリを編集すると、カテゴリ別カードも自動で再集計されます。

## v0.2.6
- `initial_item_master.csv` から消えていた以下の列を復元しました。
  - 取得状況
  - 使用材料
  - 対応加工機
  - 最終更新
- CSV列は既存項目を削除せず、植付季節・収穫季節を追加する構成に統一しました。
- CSVの「取得状況」が取得済の場合、ブラウザにその図鑑番号の取得状況がまだ保存されていないときだけ初期値として反映します。既存のLocalStorage側の取得状況を優先します。
- CSV書き出しでは15列すべてを保持します。
