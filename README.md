# ほの暮らしコンプチェッカー v0.2.4

- GitHub Pages上の `initial_item_master.csv` を起動時に毎回読み込みます。
- 取得済み/未取得とサイト内編集データはLocalStorageに保存します。
- 季節（春・夏・秋・冬）を任意・複数設定できます。
- 対応加工機・使用材料を一覧ラベルに表示します。

## v0.2.4
- アイテム編集画面に「対応加工機として選択可能」を追加。
- ONにしたアイテムだけ「対応加工機」の候補一覧に表示。
- CSVに `加工機候補` 列を追加し、候補設定の読み書きに対応。
- 既に別アイテムから対応加工機として参照されているものは、設定変更時に候補から消えても入力値を維持。
- 初期データでは #0640〜#0670 と #0674〜#0676 を加工機候補ONに設定。#0655「粉挽き」/ #0656「粉挽き／改」を含みます。
