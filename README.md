# ほの暮らしコンプチェッカー v0.1

## 使い方
1. `index.html` をChrome / Edge / Safariなどで開く。
2. 一覧の行または「未取得 / 取得済」ボタンで取得状態を切り替える。
3. 「編集」からアイテム名、カテゴリ、売値、入手方法、メモ、使用材料、対応加工機を登録する。
4. 編集内容と取得状況はブラウザのLocalStorageに自動保存される。
5. 定期的に「JSONバックアップ」を保存しておくと安全。
6. 「CSV書き出し」で、その時点の全2428件＋取得状況＋レシピ情報をCSV化できる。

## データの考え方
- `initial_item_master.csv` は初期マスター。普段は直接編集しなくてOK。
- ユーザー編集はブラウザ内データとして保持。
- JSONバックアップ/復元で別端末への移行も可能。
- 使用材料は「図鑑番号 | 名前」で既存アイテムと紐付け可能。未登録名も直接入力できる。

## 注意
- ブラウザのサイトデータを消すとLocalStorageも消えるため、JSONバックアップ推奨。
- `file://` で開く場合、ブラウザによってLocalStorageの扱いが異なることがある。将来公開する場合はWebサーバー上に置くのがおすすめ。
